# تطبيق روتين أسماء اليومي والأسري 🌸
## (Asmaa's Daily & Family Routine Web App)

تطبيق ويب مخصص للموبايل والكمبيوتر، بواجهة عربية كاملة وتصميم داعم ومريح نفسياً، مبني خصيصاً لمساعدة **أسماء** في تنظيم وإدارة روتين حياتها اليومية والأسرية بكل مرونة وبدون أي ضغط أو لوم.

---

## 🌟 أبرز مميزات التطبيق

1. **اليوم (الخط الزمني المباشر):**
   - بطاقة بارزة ومميزة للنشاط القادم مباشرة (Next Activity Hero).
   - بطاقة دائمة لـ **ورد القرآن الكريم (ساعة البركة)** في الصباح مع زر إتمام لطيف.
   - فلترة سريعة للمهام (القرآن، سليم، مراد، البيت، الوجبات، عنايتي، مشاوير).
   - إمكانية الإنجاز مع نغمات هادئة (Audio Chime) بدون ملفات خارجية.
   - أزرار مرونة ورفق: "تأجيل ساعة"، "تأجيل للمساء"، أو "نقل إلى الغد".
   - عبارات تشجيعية متجددة تدعم نفسية أسماء وتقدّر مجهودها.

2. **جدولي والتقويم الأسبوعي:**
   - استعراض الأيام وإضافة أي موعد أو نشاط مع تحديد الوقت، المدة، والتكرار (مرة، يومي، أسبوعي، شهري).
   - تحكم كامل في توقيت جلسة القرآن الصباحية وتحديد أيام تكرارها.
   - **نظام كشف التضارب الذكي (Conflict Detection):** تنبيه فوري عند وجود نشاطين في نفس الوقت مع زر مراجعة وتعديل مرن.

3. **تنظيف وتنظيم البيت:**
   - عرض المهام حسب **الغرف والمساحات** (المطبخ، الحمامات، غرف النوم، المعيشة، الغسيل) أو حسب **وتيرة التكرار** (يومي سريع، يوم بعد يوم، أسبوعي، شهري عميق).
   - مدة تقديرية لكل مهمة وإمكانية إضافة أو تعديل أو حذف أي مهمة.

4. **خطة الوجبات الأسبوعية (7 أيام):**
   - ثلاثة مسارات مخصصة وواضحة لكل يوم:
     - 🍱 **لانش بوكس سليم:** أفكار وجباته المدرسية وملاحظات التجهيز.
     - 🍲 **وجبة العائلة الرئيسية:** غداء البيت ومقاديره وطريقة تحضيره المسبق.
     - 🍽️ **عشاء مراد:** خياراته وتفضيلاته الخاصة للعشاء.
   - زر **"نسخ الوجبة ليوم آخر"** لسهولة الاستفادة من بواقي الطعام أو الأكلات المكررة.
   - زر **"أضف المقادير لقائمة المشتريات"** لنقل كل المكونات بضغطة زر واحدة إلى قسم التسوق!

5. **المشتريات والمشاوير (4 أقسام متخصصة):**
   - 🥦 **مشتريات الثلاجة (الأربعاء):** الخضار، الفواكه، الألبان والأجبان الطازجة أسبوعياً.
   - 🥩 **مشتريات أول الشهر:** اللحوم، الدواجن، المنظفات ومساحيق الغسيل بالجملة.
   - 🌾 **أساسيات المونة والتموين:** الأرز، المكرونة، الزيوت، المعلبات والتوابل.
   - 🚗 **مشاوير وطلبات طارئة:** الصيدلية، الخياط، والطلبات الخاصة.
   - إمكانية شطب ما تم شراؤه، وتنظيف المشتريات، واسترجاع القوائم الدورية المقترحة.

6. **عنايتي ولحظاتي الخاصة 🌸:**
   - مساحة خاصة لأسماء للاعتناء بنفسها وصحتها وجمالها (بشرة وشعر، مشي ورياضة، هدوء وقراءة، راحة ونوم).
   - تذكيرات رقيقة واقتباسات تعزز تقدير الذات والراحة النفسية.

7. **الخصوصية التامة والحفظ المحلي:**
   - التطبيق يحفظ البيانات محلياً بالكامل على المتصفح عبر `localStorage`.
   - لا يحتاج لأي تسجيل دخول أو خوادم خارجية، ولا يشارك أي تفاصيل عائلية.
   - إمكانية تنزيل نسخة احتياطية من البيانات بصيغة JSON واسترجاعها في أي وقت.

---

## 🚀 طريقة التشغيل

التطبيق جاهز للعمل فوراً:
1. افتحي المتصفح وانتقلي إلى:
   ```
   http://localhost:4173/
   ```
   أو افتحي ملف `index.html` مباشرة في أي متصفح على الموبايل أو الكمبيوتر.
2. يمكنك استخدام التطبيق على الهاتف المحمول بسهولة وإضافته للشاشة الرئيسية (Add to Home Screen) كتطبيق ويب مستقل.
